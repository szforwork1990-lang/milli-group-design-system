Renders the official Milli Group logo artwork; use it anywhere a mark or lockup appears.

```jsx
<Logo variant="lockup-white" width={360} base="../assets/logo" />
```

- `lockup-*` = mark + "MilliGroup" wordmark (the bold-Milli cut used on covers and end slides).
- `lockup-light-*` = the all-light wordmark cut.
- `mark-*` = the "mi" glyph with the mango dot, for tight corners and favicons.
- `wordmark-*` = type only, no mark.
- `base` must be set to the relative path of `assets/logo` from the page importing it.
